# Семейный менеджер задач

Общее пространство домашних задач для семьи из нескольких человек. Задачи живут в списках и группируются по срокам, а не по стадиям работы.

## Язык

### Единицы работы

**Задача**:
Единица работы по дому, у которой есть срок, исполнитель, приоритет и признак выполнения. Основная сущность продукта.
_Avoid_: дело, карточка, card, таск

**Подзадача**:
Задача, вложенная в другую задачу. Допускается ровно один уровень вложенности.
_Avoid_: субтаск, дочерняя задача

**Пункт**:
Строка чек-листа внутри задачи — например, товар в списке покупок. У пункта нет ни срока, ни исполнителя, и вне своей задачи он не существует.
_Avoid_: задача, подзадача, элемент

**Чек-лист**:
Набор пунктов внутри одной задачи. Канонично называть его чек-листом, а не списком, чтобы не путать со Списком.
_Avoid_: список (в значении «список покупок» допустимо в интерфейсе, но не в спеках и тикетах)

### Организация

**Список**:
Именованная область домашней жизни, в которой лежат задачи: «Наш дом», «Дача», «Отпуск».
_Avoid_: доска, board, проект, раздел

**Агенда**:
Основной экран: задачи, разложенные по группам сроков. Показывается либо для одного списка, либо сразу для всех — это один и тот же экран с разным охватом.
_Avoid_: доска, канбан, лента

**Группа**:
Корзина агенды, в которую задача попадает автоматически по своему сроку: «Просрочено», «Сегодня», «Завтра», «На этой неделе», «Позже», «Когда-нибудь». Группа вычисляется и не может быть назначена вручную.
_Avoid_: колонка, секция, статус

### Состояния

**Выполнена**:
Задачу сделали. Хранится как момент выполнения и человек, который её отметил. Свойство самой задачи, а не её местоположения.
_Avoid_: готово, закрыта, done

**В архиве**:
Задача или список больше не актуальны и убраны с глаз — независимо от того, были ли они выполнены. Отменённая поездка отправляет задачу про билеты в архив, но не делает её выполненной. В счётчик выполненного попадает только «Выполнена».
_Avoid_: удалена, скрыта

**Срок**:
Момент, к которому задачу нужно сделать. Может отсутствовать — тогда задача попадает в группу «Когда-нибудь».
_Avoid_: дедлайн, дата

### Сопровождение

**Повтор**:
Правило, по которому задача порождает следующий экземпляр себя. Одновременно открытым может быть не больше одного экземпляра.
_Avoid_: рекуррентность, recurrence

**Уведомление**:
Сообщение, которое человек получает на своё устройство. Напоминание — частный случай уведомления.
_Avoid_: пуш, нотификация, алерт

**Напоминание**:
Личное уведомление конкретного человека, привязанное к сроку задачи. У одной задачи у разных людей могут быть разные напоминания.
_Avoid_: алерт, пуш, нотификация

**Событие**:
Факт изменения в общем пространстве — задачу создали, выполнили, прокомментировали. Порождает запись во Входящих у всех, но уведомлением на устройство становится не всякое.
_Avoid_: ивент, экшен

**Устройство**:
Место доставки уведомлений: телефон, браузер на ноутбуке. У одного человека их несколько, и появление нового не отключает остальные.
_Avoid_: подписка, эндпоинт, токен, девайс

**Входящие**:
Список уведомлений внутри приложения. Показывает и то, о чём не жужжало на устройстве.
_Avoid_: инбокс, лента, колокольчик
